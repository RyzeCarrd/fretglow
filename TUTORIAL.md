## Start here

A simple first setup, from plugging in to keeping your colours on the guitar.

### What FretGlow does

FretGlow changes the lights and keyboard controls on your supported guitar. Each fret can be any colour. The names Green, Red, Yellow, Blue and Orange identify the physical buttons; they do not restrict the colours you can choose.

### The three things to remember

A preset is a saved set of colours, brightness, press effects and keys.

A guitar slot is one of three places inside the controller where you can store a preset.

Firmware is the software running inside the controller. Installing firmware adds features. Saving a preset changes your choices.

### Your first setup

1. Plug in the guitar and click Connect.
2. Pick your colours in the main window, then click Preview.
3. Open My presets, enter a name such as Purple, and click Save current as preset.
4. Select that saved preset and click Assign beside slot 1.
5. Select Startup beside that slot, then click Save slots to guitar. Keep any other assigned slots you want.
6. Wait for the saved message, then close FretGlow. Your guitar can now use that preset without the app.

### If the app asks for a firmware update

Open the Updates and Undo topic before continuing. You only need an update when the installed guitar software lacks a feature you want. You do not need to reinstall firmware every time you change a colour.

### How to use this guide

Read in order with Next, or click a topic on the left. Search for a word such as purple, save, keyboard or update to find a topic. Scroll inside the page for longer instructions. Keep this guide open beside the main window while you work.


<a id="connect"></a>
## Connect the guitar

Get the app and controller ready before changing settings.

### 1. Open the app

If you downloaded FretGlow, extract the ZIP first. Open FretGlow.exe inside the extracted folder. Keep the _internal folder beside it; the app needs those files. Close an older copy before opening an updated version.

### 2. Plug in and connect

Plug the guitar into this PC with a USB cable that carries data. Click Connect at the top right of FretGlow. Look for Connected · Pico near that button. If it already says Connected, you can continue.

### 3. If it will not connect

The guitar must be in controller mode. If it is currently typing letters, hold only the button above the bottom Start button for five seconds, then release it. Wait for the guitar to reconnect and click Connect again. Keep the bottom Start button released during this hold.

### What the colours on screen mean

The main window shows the choices saved in this Windows app. It does not automatically copy the guitar’s saved presets back onto the screen. Changing a field also does not mean you have saved that change inside the guitar.

### Automatic lighting on connection

Apply saved lights on connect automatically starts a preview of this PC’s settings when the app connects. Turn it off if you prefer the guitar to keep showing its own saved lighting until you click Preview.


<a id="colours"></a>
## Change any fret colour

Example: make the physical red fret purple.

### 1. Choose the physical fret

Find the Red row under Frets. Click its small coloured square. The window title says Red fret so you know which physical button you are editing. You can still choose purple, blue, white or any other colour.

### 2. Pick from the full rainbow

Click or drag anywhere in the rainbow. Moving left or right chooses the colour. Moving down makes it paler, towards white. The small colour squares below the rainbow are quick choices; click the purple square for an immediate purple selection.

### 3. Adjust the shade

Move Light / dark right for a brighter shade, or left for a darker shade. Fully left makes black. The preview square shows the colour you are choosing. Click Use colour to put it in the fret row. Cancel closes the picker without applying your selection.

### An exact purple you can copy

Enter #8B5CF6 in the picker’s hex field and click Use colour. A hex code is simply a written colour value. You can also type it directly in the Red row in the main window, then press Enter. Repeat for any other fret you want to change.

### 4. See it on the guitar

Click Preview. With preview active, further changes appear on the guitar as you edit. The main Brightness slider changes the overall strength of the lights. This is separate from Light / dark, which changes the shade of one chosen colour.

### Keep your changes

Preview lets you try the lights. To keep a named set, follow Make a preset. To write the current choices straight to the active guitar slot, click Save to guitar and wait for the saved message. End preview or closing the app returns lighting control to the guitar.


<a id="press-effect"></a>
## Colour when you press

Choose whether a fret changes colour when you press it.

### Normal colour and press colour

The colour in each fret row is its normal colour. The Colour square beneath Press effect is the press colour. For example, a fret can normally be purple and change to white when pressed. The press colour can be anything, including pink, blue or black. One press colour is shared by all five frets within that preset.

### Off

The fret keeps its normal colour when pressed. Choose Off if you do not want the lights to react to your fingers.

### While held

Press a fret: it shows the press colour.
Let go: it returns to its normal colour.

Example: purple → hold the fret → white → release → purple.

### Toggle

Press and release a fret once: it stays on the press colour.
Press that same fret again: it returns to its normal colour. Each fret switches independently.

Example: purple → first press → white → second press → purple.

### Set it and save it

Choose a mode from Press effect. Click the Colour square underneath it, pick a colour and click Use colour, or enter a hex code. Try it with Preview. The effect is included when you save or replace a preset and when you save settings to the guitar.


<a id="saving"></a>
## Which Save button?

Choose where your settings need to live.

### Preview / End preview

Preview temporarily shows the app’s lighting choices on the connected guitar. End preview lets the guitar use its saved lighting again. Neither button creates a named preset or permanently saves colours inside the guitar.

### Save on this PC

Remembers the main-window settings and app appearance for this Windows account. It does not update the guitar’s saved settings and does not create a named preset. Use it when you want the app to reopen with these choices.

### Save current as preset

Inside My presets, this creates a named copy of the current colours, brightness, press effect and keys. It stays in the Saved on this PC library. It is not on the guitar until you assign it to a slot and click Save slots to guitar.

### Save slots to guitar

Inside My presets, this sends the entire displayed slot arrangement to the controller, including which slot is Startup. The startup slot becomes active immediately. This is the clearest route when you want to know exactly what is in each guitar slot.

### Save to guitar

In the main window, this writes the current settings to whichever guitar slot is active. It leaves other guitar slots alone. If you have not set up multiple slots, it saves one set of settings. It does not also replace a named preset in the PC library.

### Example: colours at a friend’s house

Save your choices as a named preset → assign it to a guitar slot → click Save slots to guitar → wait for the saved message. You can then close FretGlow, unplug the guitar and take it to another compatible PC. The guitar carries the saved slots with it.


<a id="make-preset"></a>
## Make a preset

Save a named set so you can use it again later.

### 1. Set up the main window

Choose all five fret colours, overall brightness, press effect and keyboard keys. These settings are saved together in a preset. App appearance, such as Slate or Violet, is separate and does not change the controller.

### 2. Open My presets

Click My presets beside Classic, Pastel and White. The left side is the library saved on this PC. The right side is where you arrange up to three presets to send to the guitar.

### 3. Name and save it

Click New preset name and type a short name, such as Purple or Pastel. Click Save current as preset. A card with that name and five colour samples appears on the left. Use a different name if that name is already saved.

### 4. Make another preset

Return to the main window and choose another set of colours or keys. Open My presets again, give this set a different name and click Save current as preset. Changing the main window does not overwrite the first saved preset.

### What happens next

You can keep more than three named presets in the PC library. The guitar has room for three assigned slots at a time. Follow Put presets on the guitar to choose which ones go with you.


<a id="guitar-slots"></a>
## Put presets on the guitar

Assign your saved presets to slots 1, 2 and 3.

### 1. Choose a saved preset

Open My presets. On the left, find the named preset you want. Click its card to select it; its outline highlights.

### 2. Put it in a slot

Either hold the mouse button on the preset card, drag it onto a slot on the right and release, or select the card and click Assign beside that slot. The slot should now show the preset’s name. Assigning a different preset replaces that slot’s entry.

### 3. Fill any other slots you want

For example, put Purple in slot 1, Pastel in slot 2 and White in slot 3. You can use one, two or all three slots. Empty slots are skipped when you switch presets. Clear removes a slot assignment from this arrangement; the named preset stays in the PC library.

### 4. Choose Startup

Click Startup beside the occupied slot you want to use when the guitar powers on. For example, choose slot 1 to start on Purple after unplugging and reconnecting. A slot must contain a preset before it can be the startup slot.

### 5. Save the arrangement

Click Save slots to guitar. Wait for the message saying the preset slots were saved. This sends all three slot entries as currently arranged, not just the highlighted card. If the app requests new firmware, use Updates and Undo, then return here.

### 6. Try it without the app

Close FretGlow. Hold both bottom round buttons together for five seconds, then release both. With the example above, Purple changes to Pastel. Repeat for White, then Purple again. Nothing changes visibly if every assigned preset uses the same colours.


<a id="edit-preset"></a>
## Edit an existing preset

Change a saved preset without making another copy.

### 1. Load the right preset

Open My presets, click the card you want to edit on the left, then click Load selected. Its colours, brightness, effect and keys are copied into the main window. Loading alone does not save anything new on the guitar.

### 2. Make your changes

Use the main window to change colours, keys, brightness or the press effect. You can move or close the presets window while editing. Click Preview if you want to see the lighting as you work.

### 3. Replace the saved copy

Return to My presets. Select the original preset’s card again, then click Replace selected. This replaces that named preset with the settings currently shown in the main window. Make sure the selected name is the one you meant to overwrite.

### 4. Update the guitar too

If that preset is assigned to a guitar slot, click Save slots to guitar and wait for the saved message. If the same preset is assigned to more than one slot, all those entries use the updated version when sent.

### Keep the original version instead

After editing, enter a new name and click Save current as preset. This creates a separate named copy. You can then assign it to a different slot. Save to guitar in the main window changes the active controller slot but does not update the PC library’s named copy.


<a id="buttons"></a>
## The two bottom buttons

Three shortcuts. Hold for five seconds, then release.

### Know which button is which

Bottom Start button: the lower of the two round buttons at the bottom of the controller.

Button above Start: the other round button directly above it. In the app’s key list, these are labelled Bottom Start and Above Start.

### Both together: next preset

Press both buttons at the same time and keep both down for five seconds. Release both. The guitar moves to the next occupied slot: 1 → 2 → 3 → 1. Empty slots are skipped. With only one occupied slot, there is no different preset to switch to.

### Bottom Start alone: saved or original lighting

Keep the upper button released. Hold the bottom Start button for five seconds and let go. This switches between the selected preset’s lighting and the original controller lighting. Hold it again to switch back. It does not move to the next preset.

### Button above Start alone: keyboard mode

Keep the bottom Start button released. Hold the button above Start for five seconds and let go. This switches between normal controller mode and the guitar’s built-in keyboard mode. The current preset stays selected.

### Make the hold work reliably

Release the buttons fully before each hold. Hold steadily for five seconds; quick taps are normal button presses. A two-button hold takes priority over the individual shortcuts, so it should not also switch keyboard mode. Test saved lighting with FretGlow closed so a preview is not involved.

### After unplugging

When you plug the guitar back in, it loads the preset marked Startup when you last saved the slots. It does not remember the last slot you cycled to before unplugging.


<a id="keys"></a>
## Choose keyboard keys

Click an assignment, then press the key you want.

### What a key binding means

A binding is the keyboard key a guitar button should type in keyboard mode. For example, assigning A to Green means pressing the physical green fret types A. This does not change the fret’s light colour.

### 1. Click the assignment

In the main window, click the key button beside the fret or control you want to change. A small Set key window asks you to press a key on your PC keyboard. Recording a binding stops the app’s keyboard mode.

### 2. Press one key on your PC keyboard

For example, press A to assign A. The recorder closes and the new name appears beside the fret. Repeat for the other frets. You can record letters, numbers, arrows, space, modifier keys and supported numpad keys. Record one key per button; this is not a recorder for combinations such as Ctrl+C.

### An example layout

Green → A
Red → S
Yellow → K
Blue → L
Orange → M

You can also assign Strum up, Strum down, Bottom Start and Above Start. Clear binding removes an assignment. Cancel leaves it unchanged. F8 is reserved for stopping the app’s keyboard mode.

### 3. Save the keys where you need them

For use without the app, save or replace a named preset, assign it to a slot and click Save slots to guitar. Alternatively, Save to guitar updates the active slot. The keys shown in the app are only used for typing after a keyboard mode is enabled.

### If the game uses different keys

The keys assigned here must match what the game expects. Open the game’s own control settings if you need to change its bindings. The next topic explains how to try typing before opening a game.


<a id="keyboard"></a>
## Use keyboard mode

Choose between typing through the app and typing directly from the guitar.

### Option A: while FretGlow is open

1. Connect the guitar in normal controller mode.
2. Set your bindings in FretGlow.
3. Turn on the Keyboard switch in the main window.
4. Open an empty Notepad window and click inside it.
5. Press the guitar frets. The assigned letters should appear.

Press F8 on your PC keyboard, or turn the Keyboard switch off, to stop this app mode. Keep FretGlow open while using it.

### Option B: without FretGlow

1. Save your keys to the guitar first.
2. Close FretGlow.
3. Hold only the button above Start for five seconds, then release. Wait for the controller to reconnect as a keyboard.
4. Click inside an empty Notepad document and try the frets.

The guitar now uses the active preset’s saved keys, even on another compatible PC without the app.

### Return to normal controller mode

For the app mode, press F8 or turn its Keyboard switch off. For the guitar’s built-in mode, hold the button above Start for five seconds again and release. F8 does not turn off the guitar’s built-in mode. Return to controller mode before connecting FretGlow to edit or update the guitar.

### Why some buttons type on release

The two bottom round buttons have hold shortcuts as well as key assignments. In the guitar’s built-in keyboard mode, a short press types on release. A long hold performs its shortcut without repeatedly typing that assigned key.


<a id="appearance"></a>
## Change the app’s look

Dark mode and themes affect the app window, not the guitar lights.

### Dark or light

Use Dark mode at the top of the main window. Turn it on for a dark background or off for a light background.

### Choose a theme

Use the theme menu beside Dark mode. Graphite, Slate, Violet and Sand change the app’s interface colours. Choosing Violet here does not make the guitar purple; change the fret colours separately.

### Remember your choice

Click Save on this PC to keep your appearance choice for the next launch. Appearance is not part of a guitar preset. Close and reopen any already-open guide or settings dialog to use a newly selected theme.


<a id="firmware"></a>
## Updates and Undo

Use this to add guitar features, not for everyday colour changes.

### When an update is needed

Firmware is the guitar’s own software. The three-slot feature needs compatible FretGlow firmware. If saving slots asks for an update, install it once. If slots already save and switch correctly, you do not need another firmware install just to change colours, keys or the app’s tutorial.

### 1. Prepare the settings to include

Return the guitar to controller mode and connect it. In My presets, arrange the slots you want. If slots are assigned, the installer includes those saved presets. If no slots are assigned, it includes the current main-window settings. If you just edited a named preset, use Replace selected before installing.

### 2. Install the update

Open Guitar setup and click Install update. You do not need to export or choose a file first. The app creates a recovery backup of the current guitar, then installs the update. Watch the status message and keep USB connected until the operation finishes.

### 3. After installation

When the completion message appears, reconnect the app if necessary. You can use Save slots to guitar or Save to guitar for later settings changes. The firmware transfer has a separate helper so it is not dependent on keeping this tutorial open.

### What Undo last update restores

Open Guitar setup and click Undo last update to restore the firmware and guitar settings from before the most recent installation. It also replaces any guitar settings saved since that backup. Undo is not a history of colour edits and does not undo every Save to guitar click.

### Keep the backup available

Open backups shows the files saved by the updater on this PC. Keep them if you want Undo available, and use the same Windows account. If an update reports an error, read the message before doing anything else; the helper may already be restoring its backup.


<a id="troubleshooting"></a>
## If something is not working

Find the symptom, then follow the steps below.

### The app cannot find the guitar

Return the guitar to controller mode by holding only the button above Start for five seconds if it is in keyboard mode. Release it, wait for reconnection and click Connect. Check the USB cable carries data, close other copies of FretGlow and try another USB port.

### The colour changes, then disappears after closing the app

You probably changed a preview. Save to guitar writes the current settings to the active slot. For a named preset, use Replace selected after editing, then Save slots to guitar. Save on this PC alone does not save the guitar’s lighting.

### The guitar starts on the wrong preset

Open My presets. Select Startup beside the occupied slot you want, then click Save slots to guitar. The startup choice has to be sent to the controller. Unplugging and reconnecting loads that slot, even if you had previously cycled to another one.

### Both buttons do not seem to change colours

Make sure at least two slots contain presets with different colours and click Save slots to guitar. Close the app. Hold both buttons together for a full five seconds, then release both before trying again. One occupied slot, or identical colours in several slots, will not show a visible change.

### A fret is dark or changes to an unexpected colour when pressed

Check the main Brightness slider and that fret’s colour. Black makes the light dark. Check Press effect too: Toggle can leave the press colour showing until you press again. For a simple colour test, choose Off and click Preview. After testing, save the choices you want.

### The guitar types the wrong letters, or none at all

Click inside an empty Notepad document so it receives the keys. Decide which keyboard mode you are using. The app mode uses the keys currently shown in FretGlow; the built-in mode uses the keys saved in the active guitar preset. Re-save the correct preset if those differ. Use the game’s own settings to match its controls.

### The old colour picker or tutorial is still showing

Close the running copy of FretGlow, extract the newer download and open FretGlow.exe from that new folder. An old shortcut may still open an older folder. Keep the new _internal folder beside its executable.

### Saving or updating shows an error

Read the message at the bottom of the app; do not assume an unsuccessful save reached the guitar. If it requests newer firmware, follow Updates and Undo. If it mentions a recovery driver or restoring a backup, keep the backup files and use that message when asking for help.


<a id="manual-files"></a>
## Manual files and recovery

Optional tools for exporting firmware or restoring a saved backup.

### Most setups do not need these options

Use Save slots to guitar for normal preset changes and Install update for a normal firmware update. Manual file options is for making a firmware file or choosing one yourself.

### Export file

Open Guitar setup → Manual file options → Export file. Choose a folder and save the .uf2 file. It contains your assigned slots, or the main-window settings if no slots are assigned. Exporting only creates a file; it does not change the connected guitar.

### Install from file

Open Guitar setup → Manual file options → Install from file and choose a compatible file generated by this app version for the supported guitar. The updater creates a recovery backup before installation. Keep USB connected until it finishes.

### Restore a backup manually

Use this when you need the Pico’s built-in recovery mode.

1. Find the correct before.uf2 backup for this guitar through Open backups.
2. Unplug the guitar’s USB cable.
3. Hold BOOTSEL on the Pico board inside the controller while reconnecting USB. BOOTSEL is not either bottom gameplay button.
4. Release BOOTSEL when the RPI-RP2 drive appears in Windows.
5. Copy the complete backup file onto that drive and leave USB connected while it transfers.
6. The drive disappears when the controller restarts.

The backup restores the earlier firmware and settings together. Do not use another controller’s backup.
